Solano Grand buyer's guide website
===================================

Files
  index.html   The whole page: HTML, CSS and JavaScript in one file.
  images/      Hero render, agent photo and the four sample floor plans.

To view: open index.html in a browser (keep the images folder next to it).

To put it online: upload this whole folder to any static host,
e.g. Netlify Drop, GitHub Pages, Vercel or Cloudflare Pages.
No build step or server code is needed.

Editing
  - Text and figures are plain HTML inside index.html.
  - Price estimator sizes: the `units` list in the <script> at the bottom.
  - Floor plan details: the `plans` list in the same script.
  - Colours: the --bg / --fg / --accent tokens at the top of the <style>.
  - WhatsApp number: search for 6597317111.

Fonts load from Google Fonts (Cormorant Garamond, Manrope).
